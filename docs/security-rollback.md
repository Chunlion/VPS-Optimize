# 安全与回滚

高风险功能会要求输入 `YES`。不确定时先创建备份，再执行修改。

## 备份范围

菜单支持三种范围：脚本与服务配置、自定义系统目录、两者一起备份。配置备份会尽量覆盖 SSH、主机名、Nginx/Caddy、443端口复用、DNS、证书、Cloudflare Token、Docker daemon 配置、Fail2ban、sysctl 和 3x-ui 关键配置。

自定义目录每行填写一个绝对路径，留空结束。例如：`/etc`、`/usr`、`/home`、`/opt/app-data`。不支持 `/`、`/proc`、`/sys`、`/dev`、`/run` 和 `/tmp`。数据库或 Docker 数据目录请先停止相关服务，文件复制不保证运行中数据一致。

恢复 `/etc`、`/usr`、`/home` 这类一级目录时，会覆盖备份内同名内容，不会删除备份中不存在的现有文件。

备份包可保存到指定绝对目录，默认是 `/etc/vps-optimize/backups/manual/`。创建成功后会显示完整路径并自动加载；该目录会被记录，之后菜单 `[16] -> [2]` 会连同 `/backups`、`/root/backups` 自动读取其中的 `.tar.gz` 备份包。例如 `/backups/etc_usr_home_20260809165222.tar.gz` 会直接出现在列表中。它不包含 Docker volume、容器业务数据、镜像和完整防火墙运行状态，也不能替代 VPS 快照。

新系统恢复时，在主菜单 `[16] -> [2]` 加载备份包，再在 `[3] -> [1]` 恢复；也可在 `[3]` 直接从自动列表或指定 `.tar.gz` 路径恢复。脚本会先检查 Nginx、Caddy、Docker、3x-ui 等组件；缺少的服务不会自动安装，恢复配置后需自行安装并启动。

备份里可能包含私钥、面板数据库和 API Token，不要公开分享。

## 常用入口

```text
主菜单 [16 配置备份与回滚]
```

常用操作：

- 创建配置备份、自定义目录备份或两者一起备份。
- 自动读取并加载现有 `.tar.gz` 备份包。
- 从备份一键回滚。
- 查看或编辑脚本已应用配置。

## 高风险操作

这些操作前建议先确认云安全组、保留当前 SSH 会话，并准备好快照或救援控制台：

- 修改 SSH 端口。
- 开启仅密钥登录。
- 修改防火墙规则。
- 切换 443 入口模式。
- 修改证书和反向代理配置。
- 启用流量达量关机。

复杂故障处理见 [失联与回滚急救手册](recovery-runbook.md)。
