# 使用前必读

所选功能可能修改系统服务、防火墙、内核参数、反向代理、Docker 和证书配置。运行前先确认备份范围和恢复方式。

::: warning 修改前保留恢复入口
保留当前 SSH 会话，准备 VPS 快照或云厂商救援控制台。修改 SSH 端口后，用新会话确认连接成功，再关闭旧会话。
:::

## 基本原则

1. 必须以 `root` 身份运行。
2. 修改 SSH 端口前，先在云厂商安全组放行新端口。
3. 高风险操作前保留当前 SSH 会话。
4. 启用 443端口复用前确认公网 `443` 当前监听者。
5. 不确定配置来源时，先备份再修改。

## 云安全组和系统防火墙

云厂商安全组和系统防火墙是两层规则。脚本可以管理系统内的 `ufw`、`firewalld`、`iptables` 或 `ip6tables` 相关规则，但不能替你打开云厂商控制台里的安全组。

修改 SSH、防火墙、443端口复用、证书和反向代理配置前，先确认云安全组已放行必要端口。

## 443端口复用注意事项

启用 443端口复用后，公网 `443` 同一时间只应由当前入口模式对应的单个服务监听：

| 入口模式 | 公网 443 监听者 |
|---|---|
| `nginx-stream` | Nginx stream |
| `tcp-peek` | `tcppeek` / `vpso-mux` |
| `xray-fallback` | Xray 主入站 |

同机部署时，Web 反代后端、3x-ui 面板、订阅服务和被入口转发的 Xray 入站通常监听 `127.0.0.1`。`xray-fallback` 的 Xray 主入站是公网入口，应监听公网 `443`，不能按本地后端配置。

## 端口连接限制

端口并发连接限制按公网端口和来源 IP 生效。对公网 `443` 设置限制时，它限制的是整个 443 入口，不能精准到某个 SNI、入站、UUID 或用户。
