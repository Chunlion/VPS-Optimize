# 第三方脚本来源

本页列出 VPS-Optimize 当前会下载并作为脚本执行的第三方项目。二进制下载、系统软件包仓库、API 服务和本项目自有的 `dog.sh`、`xui-custom-manager.sh` 不在此表中。

远程脚本可能随上游更新而变化。执行前请核对项目地址和脚本内容。
