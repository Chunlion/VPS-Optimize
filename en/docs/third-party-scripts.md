# Third-party Script Sources

This page lists third-party projects that VPS-Optimize currently downloads and executes as scripts. Binary downloads, system package repositories, API services, and this project's own `dog.sh` and `xui-custom-manager.sh` are excluded.

Remote scripts can change upstream. Review the project URL and script content before running one.
