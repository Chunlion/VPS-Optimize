# Supported Systems

| system | Support status | Remarks |
|---|---|---|
| Debian 11/12 | Recommended | Better stability |
| Ubuntu 20.04/22.04/24.04 | Recommended | Better stability |
| Rocky/Alma/CentOS Stream | Available | Some components depend on software sources |
| Alpine | Not supported | Not recommended to run |
| OpenVZ old system | Not recommended | Kernel functionality may be missing |

## Check before running

- The system time is accurate.
- The package manager is not occupied by other processes.
- DNS can be parsed normally.
- The cloud security group allows port SSH.
- The current SSH session remains undisconnected.
