# Руководство по 3x-ui+Reality перенесено

Развёртывание 3x-ui, REALITY, панели, подписок и всех трёх режимов входа на порту 443 теперь описано на странице [Порт 443: развёртывание и настройка](../docs/443-single-entry.md). Эта страница сохранена для совместимости со старыми ссылками.

Примечание по версиям:

- 3x-ui v3.4.0 и новее: откройте `Hosts / Host` и добавьте Host.
- 3x-ui v3.3.1 и более ранние версии: откройте `External Proxy` во входящем REALITY.

Примечания по совместимости:

`panel.example.com -> текущий Web-обратный прокси (Caddy или Nginx, например 127.0.0.1:8443)`

Если в `/etc/vps-optimize/sni-stack.env` нет `ENTRY_MODE`, скрипт рассматривает конфигурацию как `nginx-stream` только при совместимом чтении старого формата.
