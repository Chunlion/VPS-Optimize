# Быстрый старт

VPS-Optimize — панель управления на Bash для повседневного администрирования VPS. Она выполняет первичную настройку сервера, оптимизацию системы и сети, базовую защиту, развёртывание узлов и типовую диагностику.

Скрипт может изменять настройки SSH и брандмауэра, параметры ядра, конфигурацию Nginx/Caddy и Docker, сертификаты и службы, использующие общий публичный порт 443. Перед запуском создайте снимок VPS, не закрывайте текущий сеанс SSH и убедитесь, что группа безопасности облачного провайдера разрешает порт SSH.

## Перед началом

- Создайте снимок VPS.
- Не закрывайте текущий сеанс SSH.
- Разрешите порт SSH в группе безопасности облачного провайдера.
- Направьте необходимые DNS-записи на этот VPS.
- При использовании Cloudflare оставьте соответствующие записи в режиме DNS only.
- Подготовьте API-токен Cloudflare, если требуется автоматическое получение сертификатов.
- Убедитесь, что на сервере установлена поддерживаемая операционная система.

## Установка из материкового Китая

```bash
wget -qO vps.sh https://ghfast.top/https://raw.githubusercontent.com/Chunlion/VPS-Optimize/main/dist/vps.sh && chmod +x vps.sh &&./vps.sh
```

## Прямая установка

```bash
wget -qO vps.sh https://raw.githubusercontent.com/Chunlion/VPS-Optimize/main/dist/vps.sh && chmod +x vps.sh &&./vps.sh
```

## Короткая команда

После первого запуска используйте глобальную команду:

```bash
cy
```

## Язык интерфейса

При первом интерактивном запуске, пока язык ещё не сохранён, установщик предлагает выбрать язык на английском:

```text
Select interface language:
  1. English
  2. 简体中文 (Simplified Chinese)
  3. Русский (Russian)
```

Нажмите Enter, чтобы выбрать английский по умолчанию. Позже язык можно изменить в пункте `[20 Язык интерфейса]` главного меню. Выбор сохраняется в `/etc/vps-optimize/language.conf`. Чтобы задать язык только для одного запуска, укажите перед командой `VPSO_LANG=zh`, `VPSO_LANG=en` или `VPSO_LANG=ru`.

## Поддерживаемые системы

| Система | Статус | Примечание |
|---|---|---|
| Debian 11/12 | Рекомендуется | Полная поддержка |
| Ubuntu 20.04/22.04/24.04 | Рекомендуется | Полная поддержка |
| Rocky/Alma/CentOS Stream | Поддерживается | Некоторые компоненты зависят от настроенных репозиториев |
| Alpine | Не поддерживается | Не запускайте скрипт |
| Старые системы OpenVZ | Не рекомендуется | Необходимые функции ядра могут отсутствовать |
