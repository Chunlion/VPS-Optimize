# Часто задаваемые вопросы

## При запуске скрипта подсказка не root

Сначала переключитесь на root:

```bash
sudo -i
```

Затем перезапустите сценарий.

## Невозможно подключиться после изменения порта SSH.

Сначала проверьте, освободила ли группа безопасности поставщика облака новый порт. Если старый сеанс SSH все еще существует, не закрывайте его.

```bash
ss -lntp | grep ssh
systemctl status ssh --no-pager || systemctl status sshd --no-pager
```

Имя службы SSH может быть `ssh` или `sshd` в разных выпусках.

## 443 Заднюю панель невозможно открыть после конфигурации с одним входом.

Приоритетные проверки:

- Контролирует ли единственная служба, соответствующая текущему режиму входа, публичный порт `443`.
- Прослушивает ли панель и подписка локальные адреса.
- 3x-ui Путь к сертификату панели очищен.
- Проходит ли проверка конфигурация механизма веб-обратный прокси.
- Разрешает ли группа безопасности облака `443/tcp`.
- Разрешается ли домен DNS текущему серверу.

Подробную информацию об устранении неполадок см. в [443 Руководство по устранению неполадок общей точки входа](443-single-entry-troubleshooting.md).

## Браузер сообщает об ошибке при доступе к внутреннему порту

443 В режиме однократного ввода браузер обращается только к стандартному адресу HTTPS:

```text
https://panel.example.com/panel/
https://sub.example.com/
```

Не обращайтесь к внутренним портам из публичной сети:

```text
https://panel.example.com:8443/
https://panel.example.com:1443/
https://panel.example.com:40000/
```

## Как вставить динамические параметры TCP

Вход:

```text
Главное меню [10 Оптимизация сети и ядра] -> [2 Динамический TCP Настройка параметров]
```

После ввода следуйте инструкциям, чтобы вставить несколько строк параметров `sysctl`. После завершения вставки введите `EOF` в другой строке и нажмите Enter, чтобы сохранить.
