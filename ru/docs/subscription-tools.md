# Управление подписками и инструменты узла

Записи, относящиеся к узлам и подпискам, сосредоточены в:

```text
Главное меню [5 панель、Узлы и инструменты подписки]
```

## Содержит контент

Этот вход используется для управления соответствующими инструментами, такими как 3x-ui, S-UI, Sing-box, Xray, SublinkPro, Sub-Store, Dockge, Komari, port Traffic Dog и комплектом расширения x-ui.

## Рекомендации по развертыванию

Средство подписки рекомендуется развертывать по схеме «локальная привязка + внешняя Caddy/Nginx/443». Недавно развернутые инструменты подписки по умолчанию сначала привязываются к `127.0.0.1`.

После включения доступа к общему доступу 443 рекомендуется добавить домен Интернета HTTPS через следующий вход:

```text
Главное меню [19 Управление повторным использованием порта 443] -> [8 менеджмент Web домены / обратный прокси]
```

Если повторное использование порта 443 не включен, можно использовать автономный точка входа обратного прокси:

```text
Главное меню [4 обратный прокси]
```

Подробные сценарии см. в разделе [Обратный прокси-сервер Caddy/Nginx и повторное использование порта 443](../tutorials/02-subscription-tools-caddy-nginx-reverse-proxy-443-single-entry.md).
