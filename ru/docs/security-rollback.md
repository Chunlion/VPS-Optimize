# Безопасность и откат

Функции высокого риска запросят `YES`. В случае сомнений создайте резервную копию перед выполнением изменений.

## Область резервного копирования

«Полное резервное копирование конфигурации» в меню относится к резервному копированию конфигурации управления сценарием, которое попытается охватить SSH, имя хоста, Nginx/Caddy, одну запись 443, DNS, сертификат, токен Cloudflare, конфигурацию демона Docker, Fail2ban, Конфигурации ключей sysctl и 3x-ui.

Он не включает том Docker, бизнес-данные контейнера, образы и полное рабочее состояние брандмауэра и не может заменить снимки VPS. Проект Compose также требует отдельного резервного копирования каталога данных и тома.

Резервная копия может содержать закрытые ключи, базу данных панели и токен API. Не делитесь ими публично.

## Повторное использование порта 443

```text
Главное меню [16 Резервное копирование и откат конфигурации]
```

Общие операции:

- Создайте полную резервную копию конфигурации (конфигурация управления сценариями, не включая полные бизнес-данные).
- Просмотрите список существующих резервных копий.
- Откат из резервной копии в один клик.
- Просмотрите или отредактируйте примененную конфигурацию сценария.

## операции с высоким риском

Перед этими операциями рекомендуется подтвердить группу безопасности облака, сохранить текущий сеанс SSH и подготовить снимок или консоль восстановления:

- Измените порт SSH.
- Включите вход только по ключу.
- Измените правила брандмауэра.
- Переключить режим входа 443.
- Измените конфигурацию сертификата и обратного прокси.
- Включить отключение объема трафика.

Подробную информацию об устранении неполадок см. в [Руководстве по оказанию первой помощи при потере соединения и откате](recovery-runbook.md).
