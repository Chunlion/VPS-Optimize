# Поддерживаемые системы

| система | Статус поддержки | Примечания |
|---|---|---|
| Debian 11/12 | Рекомендуется | Лучшая стабильность |
| Ubuntu 20.04/22.04/24.04 | Рекомендуется | Лучшая стабильность |
| Rocky/Alma/CentOS Stream | Доступно | Некоторые компоненты зависят от источников программного обеспечения. |
| Alpine | Не поддерживается | Не рекомендуется запускать |
| OpenVZ старая система | Не рекомендуется | Функциональность ядра может отсутствовать |

## Проверьте перед запуском

- Системное время указано точно.
- Менеджер пакетов не занят другими процессами.
- DNS можно разобрать обычным образом.
- Группа облачной безопасности освободила порт SSH.
- Текущий сеанс SSH остается неразъединенным.
