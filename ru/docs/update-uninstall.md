# Обновление и удаление

## обновить скрипт

Рекомендуется обновляться через меню скрипта:

```text
17. Обновить скрипт
```

Главное меню кэширует удаленную версию. После обнаружения новой версии введите `u`, `update` или `upd`, чтобы начать процесс обновления.

Встроенное обновление сначала выполнит проверку синтаксиса, а затем загрузит файл проверки; если проверка не удалась, текущая команда `cy` не будет перезаписана.

## Обновление вручную

Выполняйте от `root`. Команды проверяют загрузку, отклоняют пустой файл и проверяют синтаксис Bash. Для полной проверки используйте обновление через меню. При ошибке установка не продолжается.

```bash
(
  tmp_file=$(mktemp /tmp/cy_update.XXXXXX.sh) || exit 1
  trap 'rm -f "$tmp_file"' EXIT
  wget -qO "$tmp_file" https://raw.githubusercontent.com/Chunlion/VPS-Optimize/main/dist/vps.sh &&
    test -s "$tmp_file" &&
    bash -n "$tmp_file" &&
    install -m 755 "$tmp_file" /usr/local/bin/cy
) && cy
```

## Удалить команду ярлыка

```bash
rm -f /usr/local/bin/cy
```

Это приведет только к удалению команды быстрого доступа и не приведет к автоматическому восстановлению конфигурации системы, измененной сценарием. Системные службы, конфигурация Nginx/Caddy, правила брандмауэра, конфигурация Docker, сертификаты и параметры ядра необходимо откатить индивидуально в соответствии с фактическими условиями.
