# CDT Monitor

[CDT Monitor](https://github.com/wang4386/CDT-Monitor) — консоль для мониторинга трафика Alibaba Cloud CDT, автоматизации ECS и просмотра расходов. VPS-Optimize развёртывает официальный образ GHCR через Docker Compose.

## Установка и доступ

Установка и управление доступны здесь:

```text
Главное меню [5 Панели, узлы и инструменты подписки] -> [16 CDT Monitor]
```

По умолчанию сервис слушает `127.0.0.1:43210`. Конфигурация Compose расположена в `/opt/cdt-monitor/docker-compose.yml`; при первом открытии запускается мастер настройки администратора.

Для публичного HTTPS настройте Caddy или Nginx в главном меню `[4 Обратный прокси]`. При включённом общем порте 443 используйте `[19 Управление повторным использованием порта 443] -> [8 Управление Web-доменами и обратным прокси]`. Не открывайте порт панели напрямую в интернет.

## Настройка консоли

В консоли добавьте учётные записи Alibaba Cloud RAM, регионы и экземпляры ECS, затем настройте пороги трафика CDT и связанные с ними действия остановки или уведомления. При необходимости настройте плановое включение и выключение, просмотр расходов и уведомления SMTP, Telegram Bot или Webhook.

Пользователю RAM следует выдать только минимальные права для запросов CDT, запросов и управления питанием ECS, а также необязательных запросов BSS.

## Переход со старого watchdog

Старый `aliyun-cdt-watchdog.sh` удалён. CDT Monitor не импортирует его конфигурацию автоматически. Повторно настройте в новой консоли учётные данные RAM, экземпляры и пороги трафика; удаляйте старые systemd-службу, таймер и каталог `aliyun-cdt-watchdog` только после активации новых правил.

## Данные и архивация

SQLite-база CDT Monitor и `master.key` хранятся в томе Docker Compose `cdt-data`. При архивации развёртывания CDT Monitor этот том удаляется. Сначала полностью сохраните резервную копию тома, иначе зашифрованные учётные данные нельзя будет восстановить.
